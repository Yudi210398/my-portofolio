2. Obtain owner approval for the task scope before editing. Complete only that task and report PASS, FAIL, or NOT RUN with evidence.
3. Keep unresolved facts as TODO. Do not publish candidate/draft work or unavailable contact/CV actions.
4. Do not install tools, commit, push, or deploy without the separate approval required by the current task and owner.
